Каталог шевронов: как пользоваться

Каталог — это папка с файлами. Он открывается в браузере без интернета, правится прямо на компьютере, а копию той же папки можно выложить в интернет для QR-кода.

Что лежит в папке

index.html           — каталог (открывать его)
data/collection.js   — все данные: знаки, разделы, приказы, настройки
data/backup/         — резервные копии данных, создаются при каждом сохранении
photos/              — фотографии знаков
prikazy/             — тексты приказов (PDF)
lib/                 — оформление, шрифты, генератор QR (не трогать)

1. Установка на Яндекс Диск

  1. Распакуйте архив и положите папку kollekciya-shevronov в папку Яндекс Диска на компьютере.
  2. Откройте index.html двойным щелчком. Лучше в Chrome, Microsoft Edge или Яндекс Браузере: в них работает сохранение прямо в папку.

Если в настройках Яндекс Диска для папки включён режим «только в облаке», сначала сделайте её доступной офлайн: иначе фото не откроются.

2. Редактирование

  1. Нажмите Редактировать в правом верхнем углу.
  2. + Знак — новый шеврон. Выберите раздел, впишите название, для иностранных знаков — страну. Внизу формы, в «Вариантах исполнения», добавьте фото, приказ, количество, кто передал.
  3. Чтобы изменить существующий знак, откройте его карточку и нажмите Изменить.
  4. + Приказ — новый нормативный акт: номер, дата, статус, ссылка на текст в интернете и файл PDF.
  5. + Раздел — новый раздел, например отдельный раздел для страны или ведомства. Кнопка Раздел у заголовка раздела переименовывает его.
  6. Внизу появится полоса «Несохранённых изменений». Нажмите Сохранить в папку. В первый раз браузер попросит выбрать папку: укажите kollekciya-shevronov и разрешите изменения. Дальше в этом окне папка запоминается.

Фото при сохранении уменьшаются до 1000 пикселей по длинной стороне и записываются в photos/. Прежняя версия данных копируется в data/backup/: если что-то пошло не так, переименуйте нужную копию в collection.js и положите в data/.

В Firefox сохранение в папку не работает: браузер скачает файл collection.js, им нужно заменить файл в data/.

Таблица CSV выгружает весь список для Excel.

3. Веб-версия для QR-кода

Яндекс Диск хранит файлы, но не показывает их как сайт. Для QR-кода папку нужно выложить на хостинг. Посетители сайта могут только смотреть: редактирование работает лишь на вашем компьютере.

Вариант А. GitHub Pages — бесплатно

  1. Зарегистрируйтесь на github.com.
  2. Создайте репозиторий (New repository) с именем kollekciya-shevronov, тип Public.
  3. Установите GitHub Desktop, войдите и выполните Clone этого репозитория в папку Яндекс Диска.
  4. Скопируйте содержимое папки каталога в склонированную папку. В GitHub Desktop: впишите комментарий → Commit to main → Push origin.
  5. На сайте GitHub: репозиторий → Settings → Pages → Source: Deploy from a branch, ветка main, папка / (root) → Save.
  6. Через 1–2 минуты сайт откроется по адресу https://ВАШ-ЛОГИН.github.io/kollekciya-shevronov/.

После каждой правки каталога: GitHub Desktop → Commit → Push. Сайт обновится сам за пару минут.

Вариант Б. Yandex Cloud Object Storage — российский хостинг

  1. В консоли Yandex Cloud создайте платёжный аккаунт. Хранение такого каталога стоит несколько рублей в месяц.
  2. Object Storage → Создать бакет: имя, например kollekciya-shevronov, доступ на чтение объектов — публичный.
  3. Загрузите в бакет всё содержимое папки каталога с сохранением подпапок.
  4. В бакете: Веб-сайт → Хостинг → главная страница index.html → Сохранить.
  5. Адрес сайта: https://kollekciya-shevronov.website.yandexcloud.net.

После правок загружайте изменённые файлы: data/collection.js, новые фото и PDF.

4. QR-код

  1. Откройте каталог на компьютере → Редактировать → Настройки → впишите адрес сайта → Готово → Сохранить в папку.
  2. Вкладка QR-код → Скачать PNG для печати. Этот код откроет сайт на любом телефоне.
  3. Опубликуйте обновлённые файлы на хостинге (п. 3), чтобы адрес попал и в веб-версию.

В настройках можно выключить показ имён тех, кто передал знаки: на сайте они будут скрыты, на вашем компьютере останутся.
